PIN de abertura


O PIN vale só neste aparelho e bloqueia a tela do painel. Ele não criptografa os dados. Quem tiver o seu token do GitHub ainda acessa o arquivo de dados.

Backup
Seus dados ficam salvos no navegador deste computador.




Proteja seus dados


Atualizar o painel (trocar o arquivo por uma versão nova) não apaga os dados, desde que você abra no mesmo navegador. Limpar os dados do navegador, trocar de navegador ou de computador apaga. Por isso, baixe um backup de vez em quando e antes de cada atualização.










Clientes novos para o Notion


Pedidos criados pelo botão "Cliente novo → Notion" na aba Comprovantes. Copie e cole na conversa com o Claude para ele cadastrar no Notion. Ficam guardados e sincronizados.










Sincronização entre aparelhos (GitHub)


Guarda os seus dados em um repositório privado do GitHub, para ver os mesmos dados no PC e no celular. O token fica salvo só neste aparelho e não entra nos backups.
