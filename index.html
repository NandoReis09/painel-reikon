Backup e restauração


Os dados ficam salvos no navegador deste aparelho. Atualizar o painel (trocar o arquivo por uma versão nova) não apaga nada se você abrir no mesmo navegador. Limpar os dados do navegador, trocar de navegador ou de computador apaga. Baixe um backup de vez em quando e antes de cada atualização.










Sincronizar clientes


Traga clientes de um arquivo .json ou .csv, por exemplo exportado do Notion. Você escolhe se atualiza os clientes que já existem ou só adiciona os novos.








Sincronização entre aparelhos (GitHub)


Guarda os seus dados em um repositório privado do GitHub, para ver os mesmos dados no PC e no celular. O token fica salvo só neste aparelho e não entra nos backups.













Clientes novos para o Notion


Pedidos criados pelo botão "Cliente novo → Notion" na aba Comprovantes. Copie e cole na conversa com o Claude para ele cadastrar no Notion. Ficam guardados e sincronizados.
